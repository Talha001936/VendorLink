# VendorLink

### Connecting Companies with Verified Vendors

VendorLink is a full-stack web platform designed to connect companies
with verified vendors. Companies can post tasks, vendors can submit
proposals, and the platform provides tools for communication,
contract generation, progress tracking, payments, and AI-powered
vendor ranking.

---

## 🚀 Features

- User registration and authentication
- Role-based access control
- Company task management
- Vendor proposal management
- AI-powered vendor ranking
- Contract generation
- Chat system
- Progress tracking
- Payment management
- Notifications
- Admin monitoring and approval
